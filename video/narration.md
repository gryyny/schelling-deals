# Narration (spoken column is what Kokoro reads)

| id | screen | spoken |
| --- | --- | --- |
| s01 | title | Four small buyers want a volume price. Usually someone has to run the pool. Here, nobody does. |
| s02 | offer | A seller publishes one offer: A P I passes, ten cents each, if at least ten sell together. Then the seller's process stops. |
| s03 | derive | Each buyer agent reads the terms and computes the escrow address on its own. Same terms, same address. Change one number, and the address changes. |
| s04 | decide | The agents are scripted, with different needs and budgets. Ada and Bo accept. Cy declines: the price is above its limit. Dee waits for a cheaper tier. |
| s05 | create | Ada and Bo send their pledges at the same moment. One account is created, both pledges count, and it has no access keys. Nobody can sign for it. |
| s06 | settle | Ten units reached. Bo settles, and the seller is paid exactly once. A second settle fails. |
| s07 | refund | The cheaper tier never filled. After its deadline, Dee claims an exact refund, without the seller. |
| s08 | deliver | Ada redeems her passes. The seller comes back, delivers a signed pass, and records its hash on chain. Anyone can verify it. |
| s09 | limits | This runs on Near test net. The contract guarantees payment only at the minimum, or a refund. It does not force delivery. |
| s10 | close | Schelling Deals. The terms are the address. No operator holds the money. |
